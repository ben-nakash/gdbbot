# GDB פתוח? ערוץ טלגרם עם התראות

ערוץ טלגרם שמפרסם הודעה רק כשהמצב משתנה:
- 🍔 **"GDB פתוח! לחצו כאן להזמנה"** (עם צלצול)
- **"GDB עכשיו סגור :("** (נשלחת בשקט)

תפעול יומיומי: **Mute / Unmute** על הערוץ, וזהו.
הבדיקה רצה בחינם ב-GitHub Actions, כל דקה, 24/7, בלי שרת ובלי מחשב דלוק.

---

## הקמה חד-פעמית (כ-10 דקות)

### 1. יצירת הבוט (2 דק')
ה"טוקן" הוא בעצם הסיסמה של הבוט. בעזרתו הסקריפט מקבל הרשאה לפרסם בשמו.
1. בטלגרם, מחפשים **@BotFather** ושולחים `/newbot`.
2. בוחרים שם (למשל `GDB Alerts`) ושם משתמש שמסתיים ב-`bot` (למשל `gdb_ben_alerts_bot`).
3. BotFather עונה עם קוד ארוך, למשל `7712345678:AAH...`. **מעתיקים אותו.** זה הטוקן.

### 2. יצירת הערוץ (2 דק')
1. בטלגרם: ✏️ ← **New Channel** ← שם (למשל `GDB פתוח?`).
2. סוג **Public**, עם קישור כמו `gdb_open_ben`. השם הזה (עם @ לפניו) הוא ה-CHANNEL_ID.
3. בהגדרות הערוץ ← **Administrators** ← **Add Admin** ← מחפשים את הבוט ← מאשרים (צריך רק "Post Messages").

### 3. GitHub (5 דק')
1. יוצרים repository **ציבורי** חדש, למשל `gdb-watcher`. (בפרויקט ציבורי ה-Actions חינמיים בלי הגבלה. הטוקן לא נחשף, כי הוא נשמר כ-secret.)
2. מעלים את `gdb_watch.py` (‏**Add file ← Upload files**).
3. **Add file ← Create new file**, ובשם הקובץ כותבים בדיוק `.github/workflows/gdb.yml`. מדביקים את התוכן של `gdb.yml` ושומרים.
4. **Settings ← Secrets and variables ← Actions ← New repository secret** ומוסיפים שניים:
   - `TELEGRAM_TOKEN` = הטוקן משלב 1
   - `CHANNEL_ID` = `@gdb_open_ben` (השם של הערוץ שלכם)

### 4. בדיקה
לשונית **Actions** ← **GDB watcher** ← **Run workflow**.
תוך כחצי דקה תופיע בערוץ הודעה עם המצב הנוכחי. מכאן זה רץ לבד.

---

## שאלות
- **איך מכבים לגמרי?** ב-Actions ← GDB watcher ← `...` ← **Disable workflow**. בשביל שקט בלבד מספיק Mute.
- **מסעדה אחרת?** מוסיפים בקובץ `gdb.yml` תחת `env:` את השורה `VENUE_SLUG: "<slug>"`. ה-slug הוא החלק האחרון בכתובת המסעדה בוולט.
- **אין הודעה בבדיקה?** ב-Actions פותחים את הריצה ומסתכלים בלוג:
  - שגיאה מטלגרם (401/400) = טוקן שגוי, או שהבוט לא אדמין בערוץ.
  - שגיאה מוולט (403) = וולט חוסמים את השרתים של GitHub. במקרה כזה צריך להריץ את הסקריפט ממחשב בבית.
